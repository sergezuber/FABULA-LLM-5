# Самый трудный путь — что делает механика в худший день

[English](HARDEST-JOURNEY.md) · [中文](HARDEST-JOURNEY.zh-CN.md) · [Русский](HARDEST-JOURNEY.ru.md)

На главной странице показан **записанный прогон** (настоящая запись, настоящая квитанция). Эта страница
показывает **полную лестницу отказов** — механизмы, которые срабатывают, когда прогон идёт хуже: повторные
красные верификации, автоматический откат файлов, направленное второе мнение из облака.

> Этот разбор — **иллюстрация возможностей**, а не записанный прогон: каждый гейт в нём — настоящий,
> выпущенный код, который можно прочитать (ссылки ниже), но именно эта последовательность собрана, чтобы
> показать всю лестницу в одной истории. Записанные прогоны лежат на [главной странице](../README.ru.md) и в
> [`docs/receipts/`](receipts/).

## Лестница, механизм за механизмом

| Ступень | Что срабатывает | Где живёт |
|---|---|---|
| красный → самопочинка | `verify_done` отдаёт настоящий падающий вывод; модель итерирует по нему | [`plugin/fabula-tools.ts`](../plugin/fabula-tools.ts) |
| зелёный без теста | reproduce-gate понижает «готово», пока изменение не проверит тест, который сначала падает, а потом проходит | [`plugin/fabula-reproduce-gate.ts`](../plugin/fabula-reproduce-gate.ts) |
| зелёный без понимания | change-quiz экзаменует агента по его же диффу | [`plugin/fabula-change-quiz.ts`](../plugin/fabula-change-quiz.ts) |
| красный ×2 (настраивается через `FABULA_REWIND_THRESHOLD`) | автооткат атомарно восстанавливает файлы до последнего зелёного чекпоинта теневого git и направляет к другому подходу | [`plugin/fabula-rewind.ts`](../plugin/fabula-rewind.ts) |
| всё ещё застрял | направляющая подсказка указывает на `escalate_to_cloud` — и обвязка вызывает его сама, потому что подсказка, которую модель может проигнорировать, — это просьба, а не механизм — одно второе мнение от более сильной модели; модель в сокете продолжает вести работу | [`plugin/fabula-escalate.ts`](../plugin/fabula-escalate.ts) |
| зелёный прогон, прошедший все гейты | квитанция Proof-of-Done выпускается сама | [`plugin/fabula-receipt.ts`](../plugin/fabula-receipt.ts) |
