# Самый тяжёлый путь — что делает механика в худший день

[English](HARDEST-JOURNEY.md) · [中文](HARDEST-JOURNEY.zh-CN.md) · [Русский](HARDEST-JOURNEY.ru.md)

На главной странице — **записанная сессия** (настоящая запись, настоящий чек). Эта страница показывает
**полную лестницу отказов** — механизмы, которые срабатывают, когда всё идёт ещё хуже: проверка краснеет
раз за разом, файлы автоматически откатываются, оболочка отправляет в облако запрос за вторым мнением.

> Этот разбор — **иллюстрация возможностей**, а не запись реальной сессии: каждый барьер в нём — настоящий
> код, уже выпущенный в продукте; его можно прочитать (ссылки ниже). Но именно эта последовательность составлена так,
> чтобы показать всю лестницу одной историей. Записанные сессии живут на [главной странице](../README.ru.md)
> и в [`docs/receipts/`](receipts/).

## Лестница, механизм за механизмом

| Ступень | Что срабатывает | Где живёт |
|---|---|---|
| красное → самопочинка | `verify_done` возвращает настоящий вывод упавших тестов; модель итерирует по нему | [`plugin/fabula-tools.ts`](../plugin/fabula-tools.ts) |
| зелёное без теста | reproduce-gate понижает «готово», пока правку не подтвердит тест, который до неё падал, а после — проходит | [`plugin/fabula-reproduce-gate.ts`](../plugin/fabula-reproduce-gate.ts) |
| зелёное без понимания | change-quiz экзаменует агента по его собственному diff | [`plugin/fabula-change-quiz.ts`](../plugin/fabula-change-quiz.ts) |
| красное ×2 (порог настраивается через `FABULA_REWIND_THRESHOLD`) | автооткат атомарно возвращает файлы к последнему зелёному чекпоинту в теневом git и подсказывает сменить подход | [`plugin/fabula-rewind.ts`](../plugin/fabula-rewind.ts) |
| всё ещё тупик | подсказка указывает на `escalate_to_cloud` — и оболочка вызывает его сама, потому что подсказка, которую модель вольна проигнорировать, — это просьба, а не механизм. Одно второе мнение от более сильной модели; за рулём остаётся подключённая модель | [`plugin/fabula-escalate.ts`](../plugin/fabula-escalate.ts) |
| зелёное через все гейты | чек о выполнении (Proof-of-Done receipt) выписывается сам | [`plugin/fabula-receipt.ts`](../plugin/fabula-receipt.ts) |
